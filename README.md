# 📺 Netflix Clone (HTML & CSS)

A simple Netflix homepage clone built using only **HTML & CSS**. This project replicates the UI of Netflix's landing page with a responsive design and modern styling.

## 🚀 Features
- 🔹 Fully responsive design  
- 🔹 Clean and modern UI  
- 🔹 Pure HTML & CSS (No JavaScript)  
- 🔹 Netflix-like layout and styling
